# Mute My Main Menu Please

A lightweight SMAPI mod for Stardew Valley that fixes the broken title screen mute button.

### What it does
- Fixes the mute button icon desync and inversion bug on the title screen.
- Keeps audio silenced when navigating through submenus (Character Creation, Load Game, Co-op) and returning to the title.
- Preserves your custom in-game volume settings instead of resetting them to 75% when unmuting.
- Automatically restores gameplay audio once your farm loads.

### Installation
1. Install the latest version of [SMAPI](https://smapi.io).
2. Download this mod and unzip `MuteMyMainMenuPlease` into your `Stardew Valley/Mods` folder.
3. Launch the game using SMAPI.
